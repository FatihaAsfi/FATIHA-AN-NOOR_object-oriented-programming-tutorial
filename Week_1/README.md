# Java Basics Programs

This folder contains simple Java programs created to practice basic Java programming concepts.

## Files

### 1. HelloWorld.java
A simple program that prints:

```
Hello World
```

**Concepts used:**
- Java class and `main()` method
- `System.out.println()`

---

### 2. StudentGrade.java
A program that:
- Accepts a student's name, ID, course name, and coding mark.
- Calculates the student's grade using `if-else` statements.
- Displays the student's details along with the assigned grade.

### Grade Scale

| Marks | Grade |
|-------:|:-----:|
| 80 - 100 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

**Concepts used:**
- Variables and data types
- User input with `Scanner`
- Conditional statements (`if-else`)
- Output formatting

---

## How to Run

 - In terminal , type java HelloWorld.java
 - In terminal ,type java StudentGrade,java
