# Tutorial Summary (Week 1–10)

| Week | Topic | Summary |
|------|-------|---------|
| **Week 1** | Java Basics | Introduction to Java syntax, variables, user input, output statements, and conditional (`if-else`) statements through a Hello World and Student Grade program. |
| **Week 2** | Classes & Objects | Created custom classes, constructors, attributes, and methods while learning how to instantiate objects. |
| **Week 3** | Inheritance & Polymorphism | Implemented parent-child class relationships, method overriding, and runtime polymorphism using `Person`, `Student`, and `Lecturer`. |
| **Week 4** | *(Reserved / No project)* | No project included in this repository. |
| **Week 5** | Encapsulation | Applied data hiding using private attributes with getter and setter methods. |
| **Week 6** | Inheritance | Extended the `Employee` class to create a specialized `Lecturer` class while using the `super` keyword. |
| **Week 7** | Abstraction | Developed an abstract `Appliance` class with multiple subclasses implementing abstract methods. |
| **Week 8** | Collections & File Handling | Built a Task Manager application using `ArrayList`, file writing, and file reading. |
| **Week 9** | GUI Programming | Developed a quiz game using Swing's `JOptionPane` with interactive dialogs and simple game mechanics. |
| **Week 10** | Repository Documentation | Organized the repository, added project documentation, and created professional README files for each weekly project. |
