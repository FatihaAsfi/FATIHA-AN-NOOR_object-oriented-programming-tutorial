# Week 2 - Student Class (Java OOP)

## Description

This project demonstrates the basic concepts of **Object-Oriented Programming (OOP)** in Java by creating a `Student` class and interacting with it through the `Main` class.

## Files

### Student.java
Defines the `Student` class with the following attributes:
- `name` (String)
- `age` (int)
- `gpa` (double)

The class includes:
- A constructor to initialize student information.
- `displayInfo()` – Displays the student's details.
- `study()` – Simulates the student studying.
- `takeExam()` – Simulates the student taking an exam.

### Main.java
Creates a `Student` object and calls its methods to display information and perform actions.

## Object Created

```java
Student s1 = new Student("Fatiha", 22, 4);
```

## Sample Output

```
Name: Fatiha
Age: 22
GPA: 4.0
Fatiha is studying.
Fatiha is taking an exam.
```

## Java Concepts Demonstrated

- Packages
- Classes and Objects
- Constructors
- Instance Variables
- Methods
- Object Instantiation
- Method Invocation

## How to Run

- java Main.java
 

## Learning Outcome

After completing this project, you should be able to:
- Create a class in Java.
- Define attributes and methods.
- Use constructors to initialize objects.
- Instantiate objects and call their methods.
- Organize Java files using packages.
